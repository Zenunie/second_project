# Kanban Task Board

A responsive Kanban board built with plain HTML, CSS, and JavaScript. Users can add tasks, drag them between **To do**, **In progress**, and **Done**, and delete tasks they no longer need. Changes are saved in the browser with `localStorage`, so the board remains intact after the page is refreshed.

## Features

- Add and delete tasks
- Move tasks between three workflow stages with the HTML Drag and Drop API
- Automatically save and restore tasks with `localStorage`
- Responsive layout for desktop and mobile screens
- Clear drag-over feedback and status-based card styling
- Accessible form labels and delete-button descriptions

## Skills Demonstrated

This project demonstrates foundational front-end development skills:

- Semantic HTML and accessible form controls
- Responsive layouts using CSS Grid, Flexbox, media queries, and custom properties
- JavaScript DOM creation and manipulation
- Form, click, and drag-and-drop event handling
- Data serialization and browser persistence with JSON and `localStorage`
- Input validation and defensive handling of invalid saved data
- Organizing application logic into small, reusable functions

Overall, it shows a solid beginner-to-intermediate understanding of vanilla front-end development and browser APIs.

## Run Locally

Open `index.html` in a modern web browser. No installation or build step is required.
